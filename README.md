# 28LOTS Produktbilder

Öffentliches Bildarchiv für Airtable und andere 28LOTS-Anwendungen.

- `png/`: transparente, hochauflösende PNG-Dateien
- `jpg/`: hochauflösende JPG-Dateien mit weißem Hintergrund
- `webp/`: kompakte WebP-Dateien für schnelle Anzeige
- `manifest.csv` und `manifest.json`: Artikelzuordnung mit vollständigen öffentlichen Raw-URLs

Dateiname ist immer die fünfstellige Katalog-Artikelnummer. Die Artikel 28155 und 28156 sind im Manifest als `fehlt` gekennzeichnet und haben keine Bilddateien.
