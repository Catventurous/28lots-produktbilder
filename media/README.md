# 28LOTS Medienbibliothek

Nicht-produktbezogenes Bildmaterial aus dem 28LOTS Produktkatalog, getrennt von den Produkt-Packshots.

## Kategorien
- Brand_und_Manufaktur
- Keyvisuals
- POS_und_Displays
- Werbemittel
- Wallpaper_und_CI
- Saison_und_Illustrationen
- Merch

## Nutzung
Die Dateien unter `webp/` sind weboptimierte WEBP-Vorschauen mit maximal 300 px Kantenlänge für Airtable, Apps und schnelle Vorschauen. Originalformat und Originalabmessungen stehen in `manifest.csv` und `manifest.json`. Die bestehenden Produktbilder in `/jpg`, `/png` und `/webp` bleiben unverändert.

Jeder Datensatz im Manifest enthält eine feste GitHub-Raw-URL.
